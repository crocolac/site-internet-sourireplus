# Connexion OVH / GitHub

Le code est gere dans ce depot. Les identifiants existants restent dans les secrets GitHub.
Le workflow manuel **OVH - verifier les connexions** teste uniquement la connexion et la presence des fichiers attendus. Il ne lit pas les bases, configurations ou dossiers clients, et ne publie aucun fichier.
Aucun nouveau site de test ne fait partie de cette organisation.

La mention Git inactif dans OVH concerne son outil natif de clonage. Ce depot utilise deja GitHub Actions pour publier sur le site existant.
