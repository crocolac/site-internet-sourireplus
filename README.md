# Site internet SourirePlus

Refonte du site de la Clinique Dentaire SourirePlus.

## Principes

- site indépendant de WordPress ;
- identité visuelle cohérente avec la borne de rendez-vous ;
- expérience responsive, accessible et rapide ;
- prise de rendez-vous reliée au système de la borne ;
- déploiement OVH automatisé depuis GitHub.

Le dossier `sourireplus.bak` présent sur l’hébergement est conservé comme source documentaire historique. Il n’est jamais publié ni modifié par le nouveau site.
